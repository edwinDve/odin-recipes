#Proyecto de Recetas

Es el primer proyecto que se realiza del curso The Odin Proyect.
Se implementaran los conceptos basicos de HTML aprendidos en las lecciones anteriores.

## 🚀 Características
* Index.html cuerpo básico de un documento HTML.
* implementación de la etiquetas <h1> </h1>encabezado.
* implementacion de la etiqueta <!--  --> comentario.
* implementación de la etiqueta <p></p> parrafo.
* implementacion de la etiqueta <strong></strong> marca el texto como importante negrilla.
* implementacion de la etiqueta <em></em> enfatiza el texto en cursiva.
* implementacion de la etiqueta <ul> <li></li>  </ul> lista no ordenadas.
* implementacion de la etiqueta <ol> <li></li>  </ol> lista ordenadas.
* implementacion de la etiqueta <a href="url" target="_self"></a> Enlace se abre en la misma pestaña atributo target
*implementacion de la etiqueta <a href="url" target="_blank"></a> Enlace se abre en una nueva pestaña cambia el atributo target
*los enlaces pueden ser absolutos o relativos
*mplementacion de la etiqueta <img src="images/dog.jpg"> imagenes no tiene etiqueta de cierre puede ser referencia absoluta o relativa.

## 🛠️ Tecnologías
Lenguaje: HTML
