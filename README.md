#Proyecto de Recetas

Es el primer proyecto que se realiza del curso The Odin Project.
Se implementaran los conceptos básicos de HTML aprendidos en las lecciones anteriores.

## 🚀 Características
* Index.html cuerpo básico de un documento HTML.
* implementación de la etiquetas <h1> </h1>encabezado.
* implementación de la etiqueta <!--  --> comentario.
* implementación de la etiqueta <p></p> párrafo.
* implementación de la etiqueta <strong></strong> marca el texto como importante negrilla.
* implementación de la etiqueta <em></em> enfatiza el texto en cursiva.
* implementación de la etiqueta <ul> <li></li>  </ul> lista no ordenadas.
* implementación de la etiqueta <ol> <li></li>  </ol> lista ordenadas.
* implementación de la etiqueta <a href="url" target="_self"></a> Enlace se abre en la misma pestaña atributo target
*implementación de la etiqueta <a href="url" target="_blank"></a> Enlace se abre en una nueva pestaña cambia el atributo target
* los enlaces pueden ser absolutos o relativos
* implementación de la etiqueta <img src="images/dog.jpg"> imágenes no tiene etiqueta de cierre puede ser referencia absoluta o relativa.

## 🛠️ Tecnologías
Lenguaje: HTML
